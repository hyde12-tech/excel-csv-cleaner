========================================
Excel/CSV データ自動整理ツール
セットアップ手順書
========================================

この手順書に沿って進めると、5〜10分で使えるようになります。
わからない部分はお気軽にメッセージでご連絡ください。

----------------------------------------
【ステップ1】Pythonをインストールする
----------------------------------------

1. ブラウザで以下のURLを開く
   https://www.python.org/downloads/

2. 「Download Python」ボタンを押す

3. ダウンロードされたファイルをダブルクリック

4. ★重要★ インストール画面の一番下に
   「Add Python to PATH」というチェックボックスがあります
   必ずチェックを入れてから「Install Now」を押してください

5. 「Setup was successful」と表示されたら完了

----------------------------------------
【ステップ2】必要なライブラリをインストールする
----------------------------------------

1. 納品フォルダの中にある「requirements.txt」を確認する

2. Windowsのスタートメニューで「コマンドプロンプト」を検索して開く

3. 以下のコマンドをコピーして貼り付け、Enterを押す
   （フォルダのパスはご自身の保存場所に合わせて変更してください）

   cd [ツールを保存したフォルダのパス]
   pip install -r requirements.txt

4. 「Successfully installed」と表示されたら完了

----------------------------------------
【ステップ3】ツールを起動する
----------------------------------------

1. 納品フォルダの中の
   「データ整理ツールを起動.vbs」をダブルクリック

2. ウィンドウが開いたらセットアップ完了です！

----------------------------------------
【使い方】
----------------------------------------

■ 単体ファイル処理（重複削除・並び替え・集計）
  1. 「単体ファイル処理」を選択
  2. 「ファイルを選択」でExcel/CSVを読み込む
  3. 実行したい処理にチェックを入れる
  4. 「実行する」を押す
  5. 保存先を選ぶ

■ 複数ファイルの統合
  1. 「複数ファイル統合」を選択
  2. 「ファイルを追加」で統合したいファイルを選ぶ
  3. 「統合する」を押す
  4. 保存先を選ぶ

----------------------------------------
【うまくいかない場合】
----------------------------------------

・「pythonが見つからない」と出た場合
  → ステップ1の「Add Python to PATH」にチェックが入っていなかった可能性があります。
    Pythonを再インストールしてください。

・その他エラーが出た場合
  → エラーメッセージをコピーしてメッセージでお送りください。
    確認してご回答します。

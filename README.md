# Excel/CSV データ自動整理ツール

ExcelやCSVファイルの面倒なデータ整理作業を、ボタン1つで自動化するツールです。

---

## できること

| 機能 | 説明 |
|---|---|
| **重複データの削除** | 同じ行が2回以上ある場合、1つにまとめる |
| **並び替え** | 好きな列を基準に昇順・降順で並び替える |
| **集計** | グループごとに合計・平均・件数を集計する |
| **複数ファイルの統合** | バラバラのファイルを1つにまとめる |

---

## 対応ファイル形式

- Excel（`.xlsx`）
- CSV（`.csv`）

---

## 動作環境

- Windows 10 / 11
- Python 3.10 以上

---

## セットアップ

**1. 必要なライブラリをインストール**

```
pip install -r requirements.txt
```

**2. 起動**

`データ整理ツールを起動.vbs` をダブルクリック

---

## 使い方

### 単体ファイル処理（重複削除・並び替え・集計）

1. 「単体ファイル処理」を選択
2. 「ファイルを選択」でExcel/CSVを読み込む
3. 実行したい処理にチェックを入れる
4. 「実行する」を押す
5. 保存先を選ぶ

### 複数ファイルの統合

1. 「複数ファイル統合」を選択
2. 「ファイルを追加」で統合したいファイルを複数選ぶ
3. 「統合する」を押す
4. 保存先を選ぶ
